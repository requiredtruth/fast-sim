## Original city and mobile controls

- Metro Grid now runs the procedural coastal city generator from the original fork. Explore its street graph, downtown, shops, neighborhoods, and waterfront. The rebuilt city uses a separate save slot from the former Metro map.
- New installations start on High graphics with both tilt controls off and Peaceful difficulty. Normal and Hard enable hostile encounters.
- The mobile Bag and Settings buttons are larger and labeled. Bag placement lets you aim, rotate, and put an individual 3D item on a surface. The item and rotation persist when saved.

## Autoplay and updates

- Launch **Autoplay Demo** and choose a world to watch the game travel, scavenge, manage supplies, craft, repair, and rest. End Demo returns to the title without changing saved trips.
- **Download APK Update** opens the official GitHub download from Android settings. Android handles installation.
- This build establishes a new release signing key. Existing APKs have different signatures, so back up local trips and mods before uninstalling them. Updates signed with the same key can install over this version.
