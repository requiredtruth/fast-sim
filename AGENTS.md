# Repository instructions

## Feature retention

Never remove, disable, hide, or replace an existing gameplay feature, control, world, mode, setting, or content category without the repository owner's express permission. Preserve its usable entry point when refactoring. If a task seems to require removing a feature, explain the tradeoff and obtain permission first.

Backward compatibility is separate from feature retention. During development, internal APIs, implementation details, and save formats may change as needed. Revisit compatibility when the game reaches a stable version.
